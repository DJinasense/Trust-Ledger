# Contributing to Trust Ledger

## Philosophy

This project is built from observed friction, not a business plan. If you're here, you probably feel the same brittleness in human-AI trust that we do.

## How to Contribute

1. **Use it** — Log your AI interactions for a week. Notice where the friction is.
2. **Share field notes** — Open an issue describing what you observed, not just what you want built.
3. **Build small** — We prefer 5 small, working PRs to 1 giant rewrite.
4. **Question the protocol** — If the Trust Ledger spec doesn't match your experience, challenge it.

## Code Guidelines

- Keep the frontend vanilla JS for now. No build step required.
- Everything must work offline first.
- Respect user data: no external calls without explicit consent.
- Accessibility matters.

## Communication

- Be direct but kind.
- Assume good intent.
- Disagreement is welcome; it's how the protocol gets better.

---

*This is a collaborative exploration. There are no maintainers, only people who've been here longer.*
