# Roadmap

## Now (Weekend Build)
- [x] Basic ledger UI (log entries, rate trust, flag corrections)
- [x] "Model of You" editor with export/import
- [x] Trust score visualization per context/model
- [x] Local-only storage
- [x] Open source under MIT

## Next (Community Driven)
- [ ] **Browser extension** — one-click ledger entry from any AI chat (ChatGPT, Claude, etc.)
- [ ] **Standard export format** — make the Model of You portable to any AI system
- [ ] **Trust API spec** — a minimal REST/JSON protocol for AI services to read user trust preferences
- [ ] **Community schemas** — let people define their own context categories and model fields
- [ ] **Offline mobile app** — PWA or native, sync when ready

## Later (If It Resonates)
- [ ] **Federated sync** — encrypted, user-controlled servers. No central trust database.
- [ ] **AI-readable manifest** — a standard way for an AI to say "I support the Trust Ledger protocol"
- [ ] **Collective intelligence** — opt-in anonymized patterns ("GPT-4 tends to be overconfident in medical contexts") without exposing individual data
- [ ] **Integration with existing tools** — Obsidian plugin, VS Code extension, etc.

## Never (Anti-Roadmap)
- Cloud-first storage by default
- "Trust scores" as social signals (leaderboards, public rankings)
- Selling ledger data for "AI training"
- Replacing human judgment with algorithmic trust

---

*This roadmap is a suggestion, not a contract. Build what you feel the friction around.*
